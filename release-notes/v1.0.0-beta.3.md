**The account switcher is now a separate plugin.** Forum 1.0.0 Beta 3 no longer contains it. To keep it, install **Account Switcher 1.0.0 Beta 1** (`com.tinsever.wcf.accountSwitcher`). It works with or without the forum.

- Existing links between accounts are taken over when the plugin is installed, no matter whether the forum is updated first or second.
- Install the plugin **before** updating the forum to also keep its settings (module switch, search, maximum number of accounts) and the group permission. Otherwise they start with the defaults: enabled, registered users may switch.

New: a package server at https://woltlab-pkgs.tin.codes/ lists all releases; WoltLab Suite then shows updates in the ACP.
