**Import: attachments keep their IDs, embedded images point at the right file again.**

If the target already had attachments, every imported attachment after the first taken ID got a shifted ID, and the references in the posts were rewritten several times. Posts then showed the wrong image or none at all.

- Importer 6.2.8 dev 3 (`com.woltlab.wcf.exporter.tar`): before the attachments are imported, the next free attachment ID of the target is moved above all IDs of the old forum. Free IDs are kept, a taken ID gets a new one above that range, and nothing shifts any more.
- Forum 1.0.0 Beta 4: references are now replaced in both forms a post can contain (`[attach]` BBCode and the HTML metacode), and only the exact ID.
- README: notes on WoltLab Suite's WebP conversion of imported images and on the allowed attachment extensions.

Use both new packages for a new import attempt, and restore the target to its state before the previous attempt first.
