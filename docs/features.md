# Features

- Board list with categories, nested categories, collapsible sections,
  statistics, users online and moderators
- Board pages with sortable thread lists and announcements
- Thread pages with quick reply, inline editing, quotes, mentions, attachments,
  polls, reactions, tags and share links
- Moderation: move, split, copy, merge, close, disable and trash threads and
  posts, including bulk actions; thread log and ACP modification log
- Per-board permissions (ACL) next to the global group permissions
- Unread, latest, unanswered, undone, watched and participated thread lists;
  thread subscriptions and notifications
- Boxes: thread list, hot threads, board list, forum statistics
- Search, sitemaps, RSS feeds of threads and RSS feed import
- Article discussions in forum threads
- Optional list view for the members list, with sortable columns
- [Data importers](importing.md) compatible with exporters written for WoltLab
  Burning Board (`com.woltlab.wbb.*`)
- English and German translations
