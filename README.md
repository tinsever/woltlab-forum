Plenum is a discussion forum for WoltLab Suite Core 6.2: boards, threads, posts,
moderation, per-board permissions and an importer for existing Burning Board
forums. It is an independent implementation and not affiliated with WoltLab GmbH.

**Status:** beta. Back up your site before installing.

## Installation

In the ACP, add the package server `https://woltlab-pkgs.tin.codes/` under
Configuration > Packages > Package Servers, then install "Plenum". Requires
WoltLab Suite Core 6.2.x.
